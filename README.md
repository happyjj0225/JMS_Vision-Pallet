# JMS Vision Pallet Tester

DobotStudio Pro 팔레타이징 프로젝트의 비전 카메라 응답과 Modbus 박스·패턴 선택을 시험하는 Windows용 테스터입니다.

## 다운로드 및 실행

[Windows 배포 ZIP](https://github.com/happyjj0225/JMS_Vision-Pallet/releases/download/v2.0.0/PalletizingTest-Windows-v2.0.0.zip)을 내려받아 압축을 풀고 `PalletizingTest_v2.exe`를 실행하세요. ZIP에 들어 있는 `사용방법.txt`에 TCP 비전, Modbus 및 진단 절차가 있습니다.

Windows 10/11의 .NET Framework를 사용하는 C# Windows Forms 앱입니다. [릴리즈 정보](https://github.com/happyjj0225/JMS_Vision-Pallet/releases/tag/v2.0.0)
